# AUREL Motors showroom

A responsive, single-page car showroom made with HTML, CSS, and JavaScript. It includes a filterable and searchable inventory, save buttons, mobile navigation, and visit/contact links. The demo uses externally hosted Unsplash photos and Google Fonts, so those visual assets need an internet connection.

## Preview locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Publish free with GitHub Pages

1. Sign in to [GitHub](https://github.com/) and create a **public** repository, for example `aurel-motors`.
2. In the repository, choose **Add file → Upload files** and upload `index.html`, `styles.css`, `script.js`, and `README.md` from this project. Commit the files to the `main` branch.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/(root)` folder, then click **Save**.
6. Wait for GitHub Pages to finish deploying. The site address appears on the Pages settings screen and usually looks like `https://YOUR-USERNAME.github.io/aurel-motors/`.

The repository must contain `index.html` in its root for this setup. GitHub Pages hosting for a public repository is free. Replace the sample vehicle details, contact email, address, and car photos with your own before presenting.
